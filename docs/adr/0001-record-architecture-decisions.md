# 0001: Record architecture decisions

- Status: accepted
- Date: 2026-11-25
- Deciders: mentor, all pairs

## Context

Eight people make technical decisions over eight weeks. We need a record of why things are the way they are.

## Decision

We write a short ADR in `docs/adr/` for every significant decision: a new library or service, a schema change, a change to the agent graph shape, or a change to the fallback chains. Copy this file and increase the number.

## Consequences

- New team members can read the history.
- Decisions are reviewed in PRs like code.
